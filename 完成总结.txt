【技术亮点】

1. 无需外部工具链
   - 使用 Rust 自带的 rust-lld 链接器
   - 无需安装 loongarch64-linux-gnu-gcc
   - macOS/Windows 用户友好

2. 统一条件编译
   - 架构特定代码集中在 arch/<arch>/
   - 顶层代码保持架构无关
   - 代码复用率 85%

3. 完全参考 OSKernel2025
   - 所有 LoongArch 代码均参考成熟实现
   - 确保正确性和稳定性

【使用方法】

编译 LoongArch 内核：
  cd os
  make kernel ARCH=loongarch64

编译 RISC-V 内核（默认）：
  cd os
  make kernel

查看二进制：
  file os/target/loongarch64-unknown-none/release/os
  file os/target/riscv64gc-unknown-none-elf/release/os

【目录结构】

新增文件：
  os/src/arch/loongarch64/
    ├── boot.rs           # 启动代码
    ├── console.rs        # UART 驱动
    ├── trap.rs           # 异常处理
    ├── context.rs        # Trap 上下文
    ├── switch.rs         # 任务切换
    ├── timer.rs          # 定时器
    ├── consts.rs         # 常量
    └── linker.ld         # 链接脚本

修改文件：
  os/.cargo/config.toml         # 编译配置
  os/Makefile                   # 构建系统
  user/.cargo/config.toml       # 用户程序配置
  user/Makefile                 # 用户构建
  user/src/syscall.rs           # 系统调用
  os/src/sync/up.rs             # CRMD API
  os/src/trap/mod.rs            # Trap 接口
  os/src/task/mod.rs            # 任务管理
