# rCore-Lab 快速开始指南

## 前置条件

- macOS 系统（已在 Apple Silicon 上测试）
- 已安装 Homebrew
- 网络连接

## 一键安装脚本

将以下内容保存为 `setup.sh`:

```bash
#!/bin/bash

set -e

echo "===================================="
echo "  rCore-Lab 环境一键配置脚本"
echo "===================================="
echo

# 颜色定义
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
NC='\033[0m' # No Color

# 检查 Homebrew
echo -e "${YELLOW}[1/8]${NC} 检查 Homebrew..."
if ! command -v brew &> /dev/null; then
    echo -e "${RED}❌ Homebrew 未安装${NC}"
    echo "请先安装 Homebrew: https://brew.sh"
    exit 1
fi
echo -e "${GREEN}✅ Homebrew 已安装${NC}"

# 安装 Rust
echo -e "${YELLOW}[2/8]${NC} 安装 Rust..."
if ! command -v rustc &> /dev/null; then
    brew install rust
fi
echo -e "${GREEN}✅ Rust 安装完成${NC}"

# 安装 rustup
echo -e "${YELLOW}[3/8]${NC} 安装 rustup..."
if ! command -v rustup &> /dev/null; then
    brew install rustup
fi
export PATH="/opt/homebrew/opt/rustup/bin:$PATH"
echo -e "${GREEN}✅ rustup 安装完成${NC}"

# 初始化 rustup
echo -e "${YELLOW}[4/8]${NC} 初始化 Rust 工具链..."
rustup default stable > /dev/null 2>&1
rustup toolchain install nightly-2024-05-02
echo -e "${GREEN}✅ 工具链初始化完成${NC}"

# 安装组件
echo -e "${YELLOW}[5/8]${NC} 安装必需组件..."
rustup component add rust-src llvm-tools-preview --toolchain nightly-2024-05-02
rustup target add riscv64gc-unknown-none-elf --toolchain nightly-2024-05-02
echo -e "${GREEN}✅ 组件安装完成${NC}"

# 安装 cargo-binutils
echo -e "${YELLOW}[6/8]${NC} 安装 cargo-binutils..."
export PATH="$HOME/.cargo/bin:$PATH"
cargo +stable install cargo-binutils --force > /dev/null 2>&1
echo -e "${GREEN}✅ cargo-binutils 安装完成${NC}"

# 安装 QEMU
echo -e "${YELLOW}[7/8]${NC} 检查 QEMU..."
if ! command -v qemu-system-riscv64 &> /dev/null; then
    brew install qemu
fi
echo -e "${GREEN}✅ QEMU 已就绪${NC}"

# 配置环境变量
echo -e "${YELLOW}[8/8]${NC} 配置环境变量..."
ZSHRC="$HOME/.zshrc"
if ! grep -q "/opt/homebrew/opt/rustup/bin" "$ZSHRC" 2>/dev/null; then
    echo 'export PATH="/opt/homebrew/opt/rustup/bin:$PATH"' >> "$ZSHRC"
fi
if ! grep -q ".cargo/bin" "$ZSHRC" 2>/dev/null; then
    echo 'export PATH="$HOME/.cargo/bin:$PATH"' >> "$ZSHRC"
fi
echo -e "${GREEN}✅ 环境变量配置完成${NC}"

echo
echo "===================================="
echo -e "${GREEN}🎉 环境配置完成！${NC}"
echo "===================================="
echo
echo "下一步操作："
echo "1. 运行: source ~/.zshrc"
echo "2. 进入项目目录: cd /path/to/rcore-lab/os"
echo "3. 运行 OS: make run"
echo "4. 退出 QEMU: Ctrl+A 然后按 X"
echo
```

## 使用方法

```bash
# 1. 保存脚本
chmod +x setup.sh

# 2. 运行脚本
./setup.sh

# 3. 加载环境变量
source ~/.zshrc

# 4. 进入项目并运行
cd /Users/mac/Desktop/project/rcore-lab/os
make run
```

## 手动安装步骤

如果自动脚本失败，按以下步骤手动安装：

### 步骤 1: 安装基础工具

```bash
# 安装 Rust 和 rustup
brew install rust rustup

# 配置 PATH
export PATH="/opt/homebrew/opt/rustup/bin:$PATH"
export PATH="$HOME/.cargo/bin:$PATH"
```

### 步骤 2: 安装工具链

```bash
# 初始化 stable 工具链
rustup default stable

# 安装项目所需的 nightly 工具链
rustup toolchain install nightly-2024-05-02
```

### 步骤 3: 安装组件和目标

```bash
# 安装 Rust 组件
rustup component add rust-src llvm-tools-preview --toolchain nightly-2024-05-02

# 安装 RISC-V 目标
rustup target add riscv64gc-unknown-none-elf --toolchain nightly-2024-05-02

# 安装二进制工具
cargo +stable install cargo-binutils
```

### 步骤 4: 安装 QEMU

```bash
brew install qemu
```

### 步骤 5: 配置环境变量

```bash
# 添加到 ~/.zshrc
cat >> ~/.zshrc << 'EOF'

# rCore-Lab 环境配置
export PATH="/opt/homebrew/opt/rustup/bin:$PATH"
export PATH="$HOME/.cargo/bin:$PATH"
EOF

# 重新加载配置
source ~/.zshrc
```

### 步骤 6: 修复 Makefile

编辑 `/Users/mac/Desktop/project/rcore-lab/os/Makefile`，将第 34 行改为：

```makefile
CHAPTER ?= $(shell git rev-parse --abbrev-ref HEAD | sed -nE 's/^ch([0-9]+).*$$/\1/p')
```

## 项目结构说明

```

├── os/                         # 内核源代码
│   ├── src/                    # 内核实现
│   │   ├── main.rs            # 内核入口
│   │   ├── lang_items.rs      # Rust 语言项
│   │   ├── syscall/           # 系统调用
│   │   ├── trap/              # 中断处理
│   │   ├── task/              # 任务管理
│   │   └── mm/                # 内存管理
│   ├── Cargo.toml             # 依赖配置
│   ├── Makefile               # 构建脚本
│   └── build.rs               # 构建前处理
│
├── user/                       # 用户态程序
│   ├── src/                   # 用户程序源码
│   │   ├── bin/              # 用户程序二进制
│   │   └── lib.rs            # 用户库
│   └── Makefile               # 用户程序构建
│
├── easy-fs/                    # 简易文件系统实现
├── easy-fs-fuse/              # 文件系统打包工具
├── bootloader/                # 引导加载程序（SBI）
│   └── rustsbi-qemu.bin      # QEMU 用 SBI
│
├── vendor/                     # vendored 依赖
└── docs/                       # 文档
    └── ZJYDocs/               # 个人文档
```

## 性能优化建议

### 编译加速
```bash
# 安装 sccache（可选）
brew install sccache

# 配置 cargo 使用 sccache
export RUSTC_WRAPPER=sccache

# 或添加到 ~/.zshrc
echo 'export RUSTC_WRAPPER=sccache' >> ~/.zshrc
```

### 并行编译
```bash
# 设置编译并行度（根据 CPU 核心数）
export CARGO_BUILD_JOBS=8

# 或在 ~/.cargo/config.toml 中配置
[build]
jobs = 8
```

## 故障排除

### 问题：命令找不到
```bash
# 确认 PATH 配置
echo $PATH | grep -o '/opt/homebrew/opt/rustup/bin'
echo $PATH | grep -o '.cargo/bin'

# 重新加载配置
source ~/.zshrc
```

### 问题：编译失败
```bash
# 清理并重新构建
make clean
make build

# 如果还是失败，查看完整错误
make run 2>&1 | tee error.log
```

### 问题：QEMU 无响应
```bash
# 结束 QEMU 进程
pkill -f qemu-system-riscv64

# 重新运行
make run
```
