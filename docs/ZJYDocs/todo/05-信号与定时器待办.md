# 信号与定时器待办事项

**日期**: 2026/06/04

---

## 1. POSIX timer 信号投递 — REALTIME 时钟支持

**现状**: `check_posix_timers()` 使用 monotonic 时间（`current_ms * 1000`）检查 timer 到期，但 `timer_settime(TIMER_ABSTIME)` 设置的是 REALTIME 绝对时间。

**问题**: `clock_settime03` 和 `timer_settime03` 会先用 `clock_settime(CLOCK_REALTIME)` 把系统时间设到 2038 年附近，然后设一个 REALTIME 绝对时间的 timer。由于我们用 monotonic 检查，这个 timer 永远不会到期。

**待办**:
- [ ] `PosixTimer` 记录 `clockid`（已有字段，但未使用）
- [ ] `check_posix_timers` 对 `CLOCK_REALTIME` 的 timer，使用 `REALTIME_OFFSET_US` 偏移后的时间来检查
- [ ] `timer_settime` 对 `CLOCK_REALTIME + TIMER_ABSTIME`，将 `value_us` 转换为 monotonic 时间存储
- [ ] 移除 `clock_settime03` 和 `timer_settime03` 的 skip list 条目

**当前 skip**: `clock_settime03`, `timer_settime03`

---

## 2. POSIX timer 全局锁竞争

**现状**: `POSIX_TIMERS` 是全局 `UPIntrFreeCell<BTreeMap<...>>`，在 timer 中断（`check_posix_timers`）和用户态 syscall（`timer_settime` 等）中都会加锁。

**风险**: 如果用户态正在 `timer_settime` 期间发生 timer 中断，`check_posix_timers` 尝试获取同一个锁会死锁。

**待办**:
- [ ] 将 `check_posix_timers` 改为 `try_exclusive_access`，获取锁失败则跳过
- [ ] 或者将 POSIX timer 迁移到 per-process 的 timer 列表中（类似 ITIMER_REAL）

## 3. sigaltstack 实现

**现状**: `sys_sigaltstack`（syscall 132）是 stub，直接返回 0。

**影响**: LTP 的 `sigaltstack01/02` 等测试预期它能设置/查询替代信号栈。

**待办**:
- [ ] 实现 SS_ONSTACK / SS_DISABLE 查询
- [ ] 在 TCB 中存储 alternate signal stack 信息
- [ ] 在信号处理时，如果设置了 SA_ONSTACK 且 alternate stack 有效，切换到 alternate stack

---

## 4. rt_sigqueueinfo 完善

**现状**: `sys_rt_sigqueueinfo` 简单委托给 `sys_kill`，忽略了 `siginfo_t` 参数。

**影响**: sigqueue 测试期望信号附带 `si_value`、`si_pid`、`si_uid` 等字段。

**待办**:
- [ ] 读取用户传入的 `siginfo_t` 结构体
- [ ] 将 `si_code`、`si_pid`、`si_uid` 等信息传递到信号处理路径
- [ ] 在 `sigtimedwait` 返回时填充正确的 `siginfo_t`

---

## 5. signalfd 完善

**现状**: `SignalFdFile` 基本可用，但阻塞等待时使用 `suspend_current_and_run_next()` 忙等。

**待办**:
- [ ] 信号到达时主动唤醒等待在 signalfd 上的任务
- [ ] 支持 `SFD_NONBLOCK` 和 `SFD_CLOEXEC` 的动态修改（通过 fcntl）
- [ ] signalfd_siginfo 的 `ssi_pid`、`ssi_uid` 等字段应填充实际值
