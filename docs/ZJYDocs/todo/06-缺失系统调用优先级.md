# 缺失系统调用优先级排序

**日期**: 2026/06/04

---

基于 LTP glibc-rv round8 日志中 `unimplemented syscall` 出现的频率排序。

## P0 — 高频命中，影响面大

| 编号 | 名称 | 命中次数 | 说明 | 实现难度 |
|------|------|---------|------|---------|
| 190 | semget | ~20+ | SysV 信号量，sem* 系列测试全部 TBROK | 中等 |
| 191 | semctl | ~15+ | SysV 信号量控制 | 中等 |
| 193 | semop | ~15+ | SysV 信号量操作 | 中等 |
| 192 | semtimedop | ~10+ | SysV 信号量带超时 | 中等 |

**说明**: SysV semaphore 系列可以参考已有的 SysV message queue（msgget/msgctl/msgsnd/msgrcv）实现模式。一次性实现 4 个 syscall 可解锁 semget01-07, semctl01-09, semop01-05 等大量测试。

## P1 — 中频命中，影响特定测试组

| 编号 | 名称 | 命中次数 | 说明 | 实现难度 |
|------|------|---------|------|---------|
| 434 | pidfd_open | ~7 | pidfd_* 测试需要 | 简单（返回 fd） |
| 439 | faccessat2 | ~5 | 带 flags 的 faccessat | 简单（转发到 faccessat） |
| 437 | openat2 | ~3 | 带 resolve flags 的 openat | 中等 |
| 280 | bpf | ~9 | eBPF，不建议实现 | 返回 EPERM |
| 435 | clone3 | ~8 | 已有但被 skip | 检查是否可取消 skip |
| 266 | clock_adjtime | ~5 | 时钟调整 | 简单 stub |
| 217 | add_key | ~5 | keyring 系统 | 返回 ENOSYS 可接受 |
| 219 | keyctl | ~5 | keyring 控制 | 返回 ENOSYS 可接受 |

## P2 — 低频或不影响得分

| 编号 | 名称 | 命中次数 | 说明 |
|------|------|---------|------|
| 268 | setns | 少量 | namespace 相关 |
| 270 | process_vm_readv | 少量 | 跨进程读内存 |
| 271 | process_vm_writev | 少量 | 跨进程写内存 |
| 425 | io_uring_setup | 少量 | io_uring |
| 234 | remap_file_pages | 少量 | 已废弃 |
| 282 | userfaultfd | 少量 | 用户态页错误 |
| 241 | perf_event_open | 少量 | 性能计数器 |

## 快速收益建议

1. **SysV semaphore (190-193)**: 预计解锁 30+ 测试，参考 msgget 实现模式
2. **pidfd_open (434)**: 简单实现，返回一个 fd 即可
3. **faccessat2 (439)**: 转发到现有 faccessat，加 flags 参数
4. **clock_adjtime (266)**: stub 返回 0
5. **openat2 (437)**: 转发到 openat，忽略 resolve flags
